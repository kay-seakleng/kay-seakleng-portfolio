Preview locally:
1. Extract this ZIP.
2. Keep index.html and the assets folder together.
3. Double-click index.html to open it in a browser.

To publish free with GitHub Pages:
1. Create a public GitHub repository.
2. Upload index.html and the complete assets folder (not just index.html).
3. Open repository Settings > Pages.
4. Select Deploy from a branch, choose main and /(root), then Save.
5. Use the published URL shown in Settings > Pages.

Check that you have permission to publish all photographs, logos and video/audio assets used in your designs. GitHub Pages sites are public.
